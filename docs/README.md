# docs/

Artefatos técnicos produzidos pela equipe: levantamento de requisitos, modelagem,
arquitetura, decisões de stack.

Não confundir com `insumos/` — lá ficam documentos **recebidos de fora** (cliente,
disciplina), que são imutáveis. Aqui fica o que a equipe **escreve**.

Nomeie os arquivos como `AAAA-MM-DD-slug.md` e registre a criação no
[`../CHANGELOG.md`](../CHANGELOG.md).
